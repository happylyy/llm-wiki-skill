# 软件资产库

## 重点概念卡片

- **正式名称**：软件资产库
- **原始术语／别名**：安全、统一的软件资产库
- **类型**：产出
- **工作定义**：软件资产全生命周期管理中建立的安全、统一的软件资产库，用于动态监管软件资产的状态。
- **核心机制**：安全统一存储软件资产 → 动态监管状态 → 支持归档、访问、复用授权。
- **在全书中的作用**：软件资产全生命周期管理的承载设施。
- **上位概念**：无
- **下位概念**：无
- **相关概念**：软件资产全生命周期管理（所属方法）、软件资产元模型（状态更新标准）
- **适用条件**：软件资产全生命周期管理时。
- **局限／边界**：原文未描述资产库的技术实现。
- **来源证据**：§5.3.3「建立安全、统一的软件资产库，并动态监管软件资产的状态：……从立项开始应该提交软件资产申请信息给软件资产管理中心进行研发类软件资产入库，在研发项目过程中，根据项目的里程碑节点及时提交所有可重复使用的工作产物信息给软件资产管理中心进行资产统一的归档、访问和复用授权管理……」
- **置信度**：高
- **建议文件名**：`software-asset-repository(软件资产库).md`
