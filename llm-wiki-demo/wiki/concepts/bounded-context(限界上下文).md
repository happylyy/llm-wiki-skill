# 限界上下文

## 重点概念卡片

- **正式名称**：限界上下文
- **原始术语／别名**：Bounded Context
- **类型**：分类
- **工作定义**：在特定边界内一致定义和使用领域模型、术语语义、业务规则及对象关系的语义边界。
- **核心机制**：在特定边界内一致定义和使用领域模型、术语语义、业务规则及对象关系的语义边界。
- **在全书中的作用**：解决同一术语或业务对象在不同语境和职责范围内含义、建模方式不同的问题。
- **上位概念**：无
- **下位概念**：无
- **相关概念**：领域、子域、信息概念
- **适用条件**：用于原文所述的软件架构设计、治理或数字化生产体系语境。
- **局限／边界**：领域和子域属于业务问题空间；限界上下文属于解决方案或建模边界。
- **来源证据**：《软件架构 核心技术语定义》§5.5，行 651–664；在特定边界内一致定义和使用领域模型、术语语义、业务规则及对象关系的语义边界。
- **置信度**：高
- **建议文件名**：`bounded-context(限界上下文).md`
