# 最小可市场化特性（MMF）

## 重点概念卡片

- **正式名称**：最小可市场化特性（MMF）
- **原始术语／别名**：Minimum Marketable Feature
- **类型**：分类
- **工作定义**：一个产品最小的、能够为用户提供价值并可以成功推向市场的功能集合。
- **核心机制**：在尽可能短的时间内提供最有价值的功能给用户，加速产品上市时间。
- **在全书中的作用**：研发项目迭代轮次的三个轮次之一，对应市场化验证阶段。
- **上位概念**：研发项目迭代轮次
- **下位概念**：无
- **相关概念**：最小可行产品（MVP）、规模化（Scaling）（并列轮次）、产品生命周期模型（市场化验证阶段）
- **适用条件**：MVP 完成初步验证后，向市场交付最小可销售功能集合时。
- **局限／边界**：原文未给出「最小功能集」的边界标准。
- **来源证据**：§3 术语「最小可市场化特性（MMF）：Minimum Marketable Feature 是一个产品最小的、能够为用户提供价值并可以成功推向市场的功能集合。核心思想是在尽可能短的时间内提供最有价值的功能给用户，加速产品上市时间。」
- **置信度**：高
- **建议文件名**：`minimum-marketable-feature(最小可市场化特性（MMF）).md`
