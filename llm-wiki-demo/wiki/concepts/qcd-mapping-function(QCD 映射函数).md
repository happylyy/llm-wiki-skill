# QCD 映射函数

## 重点概念卡片

- **正式名称**：QCD 映射函数
- **原始术语／别名**：QCD Mapping Function
- **类型**：机制
- **工作定义**：以产品研发环境度量结果为输入，结合生产活动和内部环境要素，把软件开发全流程转化为质量、成本、交付评价预测，实现产品线资产能力向项目过程管理的量化。
- **核心机制**：以产品研发环境度量结果为输入，结合生产活动和内部环境要素，把软件开发全流程转化为质量、成本、交付评价预测，实现产品线资产能力向项目过程管理的量化。
- **在全书中的作用**：连接 PDT 与 PPM。
- **上位概念**：三层映射
- **下位概念**：无
- **相关概念**：产品研发环境（PDT）、生产过程管理环境（PPM）、三层映射、TPP 要素
- **适用条件**：用于原文所述的软件架构设计、治理或数字化生产体系语境。
- **局限／边界**：以原文给出的定义和适用语境为限。
- **来源证据**：《四层环境三层映射 核心术语定义》§4.2.1，行 847–849及 p39 图；以产品研发环境度量结果为输入，结合生产活动和内部环境要素，把软件开发全流程转化为质量、成本、交付评价预测，实现产品线资产能力向项目过程管理的量化。
- **置信度**：高
- **建议文件名**：`qcd-mapping-function(QCD 映射函数).md`

## 运行机制

输入为 PDT 的生产力度量结果、生产活动和内部 TPP 要素；转换内容为质量、成本、交付评价预测；输出进入 PPM，用于量化产品线资产能力对应的项目过程管理表现（§4.2.1及 p39 图）。
