# 应用

## 重点概念卡片

- **正式名称**：应用
- **原始术语／别名**：Application；应用级软件构块；C4 Container
- **类型**：分类
- **工作定义**：系统中可独立部署运行的单元，代表应用程序或数据存储，封装执行环境或数据，并通过网络与其他应用通信。
- **核心机制**：系统中可独立部署运行的单元，代表应用程序或数据存储，封装执行环境或数据，并通过网络与其他应用通信。
- **在全书中的作用**：作为系统内部可独立部署运行的软件构块。
- **上位概念**：系统
- **下位概念**：组件
- **相关概念**：系统、组件、应用架构、构块
- **适用条件**：用于原文所述的软件架构设计、治理或数字化生产体系语境。
- **局限／边界**：以原文给出的定义和适用语境为限。
- **来源证据**：《软件架构 核心技术语定义》§3.4，行 505–507；系统中可独立部署运行的单元，代表应用程序或数据存储，封装执行环境或数据，并通过网络与其他应用通信。
- **置信度**：高
- **建议文件名**：`application(应用).md`
