# 数据模型

## 重点概念卡片

- **正式名称**：数据模型
- **原始术语／别名**：Data Model
- **类型**：模型／框架
- **工作定义**：对某一范围内数据对象、属性、关系及约束规则的结构化描述。
- **核心机制**：对某一范围内数据对象、属性、关系及约束规则的结构化描述。
- **在全书中的作用**：表达局部数据对象结构，与全局数据架构区分，并统摄概念、逻辑、物理模型。
- **上位概念**：数据架构
- **下位概念**：概念模型、逻辑模型、物理模型
- **相关概念**：数据架构、概念模型、逻辑模型、物理模型、数据实体
- **适用条件**：用于原文所述的软件架构设计、治理或数字化生产体系语境。
- **局限／边界**：以原文给出的定义和适用语境为限。
- **来源证据**：《软件架构 核心技术语定义》§5.8，行 696–705；对某一范围内数据对象、属性、关系及约束规则的结构化描述。
- **置信度**：高
- **建议文件名**：`data-model(数据模型).md`
