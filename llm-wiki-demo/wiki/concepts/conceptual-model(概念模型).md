# 概念模型

## 重点概念卡片

- **正式名称**：概念模型
- **原始术语／别名**：Conceptual Model
- **类型**：模型／框架
- **工作定义**：从业务视角高层抽象问题域中的核心对象、主要概念及其关系，强调业务语义，不关注具体实现。
- **核心机制**：从业务视角高层抽象问题域中的核心对象、主要概念及其关系，强调业务语义，不关注具体实现。
- **在全书中的作用**：作为数据模型的高抽象层，回答业务中有哪些核心对象及关系。
- **上位概念**：数据模型
- **下位概念**：无
- **相关概念**：数据模型、逻辑模型、物理模型、信息概念
- **适用条件**：用于原文所述的软件架构设计、治理或数字化生产体系语境。
- **局限／边界**：以原文给出的定义和适用语境为限。
- **来源证据**：《软件架构 核心技术语定义》§5.9，行 707–718；从业务视角高层抽象问题域中的核心对象、主要概念及其关系，强调业务语义，不关注具体实现。
- **置信度**：高
