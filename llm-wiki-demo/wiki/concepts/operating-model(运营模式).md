# 运营模式

## 重点概念卡片

- **正式名称**：运营模式
- **原始术语／别名**：Operating Model
- **类型**：模型／框架
- **工作定义**：描述业务如何运营，涉及人员、流程和技术，补充业务架构的 How 视角。
- **核心机制**：描述业务如何运营，涉及人员、流程和技术，补充业务架构的 How 视角。
- **在全书中的作用**：说明战略导向的业务架构如何转化为可运营方式。
- **上位概念**：无
- **下位概念**：无
- **相关概念**：业务架构、业务流程、技术架构
- **适用条件**：用于原文所述的软件架构设计、治理或数字化生产体系语境。
- **局限／边界**：以原文给出的定义和适用语境为限。
- **来源证据**：《软件架构 核心技术语定义》§4.2，行 586–593及“业务架构与运营模式的关系”图；描述业务如何运营，涉及人员、流程和技术，补充业务架构的 How 视角。
- **置信度**：高
- **建议文件名**：`operating-model(运营模式).md`
