# 软件资产

## 重点概念卡片

- **正式名称**：软件资产
- **原始术语／别名**：Software Asset
- **类型**：分类
- **工作定义**：组织拥有或有权使用、以物理形态存在的软件资源；其物理形态分为系统、应用和组件。
- **核心机制**：组织拥有或有权使用、以物理形态存在的软件资源；其物理形态分为系统、应用和组件。
- **在全书中的作用**：统一软件生产视角下的资产对象，并为系统、应用、组件的层级划分提供上位概念。
- **上位概念**：无
- **下位概念**：系统、应用、组件
- **相关概念**：软件资产的复用、系统、应用、组件
- **适用条件**：用于原文所述的软件架构设计、治理或数字化生产体系语境。
- **局限／边界**：这里按物理形态描述软件资源，不等同于从销售用途观察的软件产品或软件解决方案。
- **来源证据**：《软件架构 核心技术语定义》§3.1，行 251–253；组织拥有或有权使用、以物理形态存在的软件资源；其物理形态分为系统、应用和组件。
- **置信度**：高
- **建议文件名**：`software-asset(软件资产).md`
