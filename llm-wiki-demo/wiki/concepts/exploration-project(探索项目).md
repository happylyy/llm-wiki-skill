# 探索项目

## 重点概念卡片

- **正式名称**：探索项目
- **原始术语／别名**：无
- **类型**：分类
- **工作定义**：面向组织长期市场机会的变革性、试验性探索活动，多处于产品生命周期模糊前端阶段（FFE - Fuzzy Front End），或虽进入开发阶段但产品概念未获有效市场验证。
- **核心机制**：面向长期市场机会的变革性探索，产品概念未充分验证、营销体系不完善、采用不成熟新技术或研发团队技术经验不足。
- **在全书中的作用**：研发项目产品成熟度的两种类型之一，对应敏态管理模式与探索项目研发预算。
- **上位概念**：研发项目的产品成熟度
- **下位概念**：无
- **相关概念**：成熟项目（对照）、敏态管理模式（对应管理模式）
- **适用条件**：目标产品具备以下一项或多项特征——产品概念未充分验证、营销体系不完善、采用不成熟新技术、研发团队技术经验不足。
- **局限／边界**：原文以「一项或多项特征」判定，未给出特征的数量阈值。
- **来源证据**：§3 术语「探索项目：是指面向组织长期市场机会的变革性、试验性探索活动，多处于产品生命周期模糊前端阶段（FFE - Fuzzy Front End），或虽进入开发阶段但产品概念未获有效市场验证。目标产品具备以下一项或多项特征：产品概念未充分验证、营销体系不完善、采用不成熟新技术、研发团队技术经验不足。」
- **置信度**：高
- **建议文件名**：`exploration-project(探索项目).md`
