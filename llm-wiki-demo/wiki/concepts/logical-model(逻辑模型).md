# 逻辑模型

## 重点概念卡片

- **正式名称**：逻辑模型
- **原始术语／别名**：Logical Model
- **类型**：模型／框架
- **工作定义**：在概念模型基础上进一步结构化描述数据对象、属性、关系、业务规则和逻辑约束，通常不绑定具体数据库或物理存储。
- **核心机制**：在概念模型基础上进一步结构化描述数据对象、属性、关系、业务规则和逻辑约束，通常不绑定具体数据库或物理存储。
- **在全书中的作用**：作为数据模型的中间抽象层，承接概念模型并为物理模型提供逻辑结构。
- **上位概念**：数据模型
- **下位概念**：无
- **相关概念**：概念模型、物理模型、数据模型、逻辑架构
- **适用条件**：用于原文所述的软件架构设计、治理或数字化生产体系语境。
- **局限／边界**：逻辑模型是数据建模层级，不等同于包含上下文、概念和逻辑级抽象的逻辑架构。
- **来源证据**：《软件架构 核心技术语定义》§5.9，行 707–718；在概念模型基础上进一步结构化描述数据对象、属性、关系、业务规则和逻辑约束，通常不绑定具体数据库或物理存储。
- **置信度**：高
- **建议文件名**：`logical-model(逻辑模型).md`
