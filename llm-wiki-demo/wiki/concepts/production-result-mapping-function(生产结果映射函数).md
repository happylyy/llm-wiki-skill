# 生产结果映射函数

## 重点概念卡片

- **正式名称**：生产结果映射函数
- **原始术语／别名**：无
- **类型**：机制
- **工作定义**：以价值交付管理环境度量结果和合同质量等要素为输入，预测软件资产业务价值成果，并与人效、元效、按期按预算等生产效率指标建立闭环映射。
- **核心机制**：以价值交付管理环境度量结果和合同质量等要素为输入，预测软件资产业务价值成果，并与人效、元效、按期按预算等生产效率指标建立闭环映射。
- **在全书中的作用**：连接 VDM 与 VSM。
- **上位概念**：三层映射
- **下位概念**：无
- **相关概念**：价值交付管理环境（VDM）、价值实现管理环境（VSM）、三层映射、VSM 要素
- **适用条件**：用于原文所述的软件架构设计、治理或数字化生产体系语境。
- **局限／边界**：以原文给出的定义和适用语境为限。
- **来源证据**：《四层环境三层映射 核心术语定义》§4.2.3，行 855–857及 p39 图；以价值交付管理环境度量结果和合同质量等要素为输入，预测软件资产业务价值成果，并与人效、元效、按期按预算等生产效率指标建立闭环映射。
- **置信度**：高
- **建议文件名**：`production-result-mapping-function(生产结果映射函数).md`

## 运行机制

输入为 VDM 的业务价值衰减预测结果及合同质量等 VSM 要素；建立业务价值成果预测与人效、元效、按期按预算指标的闭环映射；输出用于预测 VSM 层的生产结果（§4.2.3及 p39 图）。
