# 参考数据

## 重点概念卡片

- **正式名称**：参考数据
- **原始术语／别名**：Reference Data；原文引用 Chisholm（2001）
- **类型**：分类
- **工作定义**：用于描述或分类其他数据，或将数据与组织外部信息联系起来的参照数据。
- **核心机制**：用于描述或分类其他数据，或将数据与组织外部信息联系起来的参照数据。
- **在全书中的作用**：与主数据、基础数据区分，提供分类、取值、约束和判断依据。
- **上位概念**：无
- **下位概念**：无
- **相关概念**：主数据、基础数据、数据架构
- **适用条件**：用于原文所述的软件架构设计、治理或数字化生产体系语境。
- **局限／边界**：典型形态是代码表、字典表和枚举表；重点是保证标准取值一致。
- **来源证据**：《软件架构 核心技术语定义》§5.10，行 720–731；用于描述或分类其他数据，或将数据与组织外部信息联系起来的参照数据。
- **置信度**：高
- **建议文件名**：`reference-data(参考数据).md`
