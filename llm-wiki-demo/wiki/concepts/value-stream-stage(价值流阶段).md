# 价值流阶段

## 重点概念卡片

- **正式名称**：价值流阶段
- **原始术语／别名**：Value Stream Stage；来源标注为 BIZBOK
- **类型**：分类
- **工作定义**：价值流从开始到结束过程中与利益相关者的一系列交流。
- **核心机制**：价值流从开始到结束过程中与利益相关者的一系列交流。
- **在全书中的作用**：将价值流分解为可交付价值项并由流程实现的阶段。
- **上位概念**：价值流
- **下位概念**：无
- **相关概念**：价值流、价值项、业务流程
- **适用条件**：用于原文所述的软件架构设计、治理或数字化生产体系语境。
- **局限／边界**：以原文给出的定义和适用语境为限。
- **来源证据**：《软件架构 核心技术语定义》§3.3，行 412–416；价值流从开始到结束过程中与利益相关者的一系列交流。
- **置信度**：高
