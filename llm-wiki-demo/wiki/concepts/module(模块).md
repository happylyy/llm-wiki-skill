# 模块

## 重点概念卡片

- **正式名称**：模块
- **原始术语／别名**：Module
- **类型**：分类
- **工作定义**：系统内部按职责、功能或变化边界划分、具有相对独立性和内聚性的组成单元。
- **核心机制**：系统内部按职责、功能或变化边界划分、具有相对独立性和内聚性的组成单元。
- **在全书中的作用**：表达系统内部逻辑分解结果，并与构块、组件区分。
- **上位概念**：无
- **下位概念**：无
- **相关概念**：构块、系统、应用、组件
- **适用条件**：用于原文所述的软件架构设计、治理或数字化生产体系语境。
- **局限／边界**：模块强调系统内部职责划分，通常不能独立运行；构块强调架构抽象，组件强调可装配、可替换、可复用的实现。
- **来源证据**：《软件架构 核心技术语定义》§5.7，行 675–694；系统内部按职责、功能或变化边界划分、具有相对独立性和内聚性的组成单元。
- **置信度**：高
- **建议文件名**：`module(模块).md`
