# 价值项

## 重点概念卡片

- **正式名称**：价值项
- **原始术语／别名**：Value Item；来源标注为 BIZBOK
- **类型**：产出
- **工作定义**：个人或组织在与一方或多方的特定互动过程中获得的、对有形或无形物品的价值判断。
- **核心机制**：个人或组织在与一方或多方的特定互动过程中获得的、对有形或无形物品的价值判断。
- **在全书中的作用**：作为价值流阶段交付并累积形成价值主张。
- **上位概念**：价值流
- **下位概念**：无
- **相关概念**：价值流、价值流阶段、价值主张
- **适用条件**：用于原文所述的软件架构设计、治理或数字化生产体系语境。
- **局限／边界**：以原文给出的定义和适用语境为限。
- **来源证据**：《软件架构 核心技术语定义》§3.3，行 406–410；个人或组织在与一方或多方的特定互动过程中获得的、对有形或无形物品的价值判断。
- **置信度**：高
- **建议文件名**：`value-item(价值项).md`
