# 功能

## 重点概念卡片

- **正式名称**：功能
- **原始术语／别名**：Function
- **类型**：分类
- **工作定义**：系统、应用、模块或产品为满足某项需求而提供的具体行为、操作或服务。
- **核心机制**：系统、应用、模块或产品为满足某项需求而提供的具体行为、操作或服务。
- **在全书中的作用**：与业务能力区分，表达系统具体做什么。
- **上位概念**：无
- **下位概念**：无
- **相关概念**：业务能力、需求、系统、应用、模块
- **适用条件**：用于原文所述的软件架构设计、治理或数字化生产体系语境。
- **局限／边界**：功能面向用户操作、系统处理或技术实现，通常相对易变；不等同于四层环境之间的量化映射“函数”。
- **来源证据**：《软件架构 核心技术语定义》§5.3，行 627–636；系统、应用、模块或产品为满足某项需求而提供的具体行为、操作或服务。
- **置信度**：高
- **建议文件名**：`system-function(功能).md`
