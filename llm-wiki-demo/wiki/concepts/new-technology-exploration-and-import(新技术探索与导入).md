# 新技术探索与导入

## 重点概念卡片

- **正式名称**：新技术探索与导入
- **原始术语／别名**：无
- **类型**：分类
- **工作定义**：对新兴技术、前沿技术开展可行性研究与原型验证，并将经过验证的成熟技术组件导入现有产品平台或业务场景，以提升产品技术能力。
- **核心机制**：新兴/前沿技术 → 可行性研究与原型验证 → 验证成熟后导入现有产品平台/业务场景 → 提升产品技术能力。
- **在全书中的作用**：技术创新类型的三种类型之一，对应 BT3 部门级项目。
- **上位概念**：技术创新类型
- **下位概念**：无
- **相关概念**：技术机制封装、对已有技术的改进（并列类型）
- **适用条件**：适用于对新兴/前沿技术的探索与导入。
- **局限／边界**：原文未说明「成熟技术组件」的判定标准。
- **来源证据**：§3 术语「新技术探索与导入：对新兴技术、前沿技术开展可行性研究与原型验证，并将经过验证的成熟技术组件导入现有产品平台或业务场景，以提升产品技术能力。」
- **置信度**：高
- **建议文件名**：`new-technology-exploration-and-import(新技术探索与导入).md`
