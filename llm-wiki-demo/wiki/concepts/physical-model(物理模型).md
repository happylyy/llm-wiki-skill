# 物理模型

## 重点概念卡片

- **正式名称**：物理模型
- **原始术语／别名**：Physical Model；原始 Markdown 出现“物埋模型是仕逻辑模型基础上”的 OCR 异常
- **类型**：模型／框架
- **工作定义**：在逻辑模型基础上结合具体技术平台、数据库类型、存储方式和性能要求形成的实现模型，包括表、字段、索引、分区及数据类型等。
- **核心机制**：在逻辑模型基础上结合具体技术平台、数据库类型、存储方式和性能要求形成的实现模型，包括表、字段、索引、分区及数据类型等。
- **在全书中的作用**：作为数据模型的低抽象实现层。
- **上位概念**：数据模型
- **下位概念**：无
- **相关概念**：逻辑模型、数据模型、物理架构
- **适用条件**：用于原文所述的软件架构设计、治理或数字化生产体系语境。
- **局限／边界**：本页按同节标题和表格规范化明显 OCR 错字；物理模型是数据库实现模型，不等同于物理架构。
- **来源证据**：《软件架构 核心技术语定义》§5.9，行 715–718；同节表格明确写作“物理模型”；在逻辑模型基础上结合具体技术平台、数据库类型、存储方式和性能要求形成的实现模型，包括表、字段、索引、分区及数据类型等。
- **置信度**：高
- **建议文件名**：`physical-model(物理模型).md`
