# 软件解决方案

## 重点概念卡片

- **正式名称**：软件解决方案
- **原始术语／别名**：Software Solution
- **类型**：分类
- **工作定义**：销售给客户、能够解决特定客户问题的软件。
- **核心机制**：销售给客户、能够解决特定客户问题的软件。
- **在全书中的作用**：从销售用途区分面向特定客户的软件交付。
- **上位概念**：无
- **下位概念**：无
- **相关概念**：软件资产、软件产品
- **适用条件**：用于原文所述的软件架构设计、治理或数字化生产体系语境。
- **局限／边界**：区别于能够重复解决多个客户问题的软件产品。
- **来源证据**：《软件架构 核心技术语定义》§3.1，行 263–265；销售给客户、能够解决特定客户问题的软件。
- **置信度**：高
- **建议文件名**：`software-solution(软件解决方案).md`
