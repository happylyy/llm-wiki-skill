# 构块、系统、应用、模块与组件

## 比较目的

本页按原文澄清 [[building-block(构块)|构块]]、[[system(系统)|系统]]、[[application(应用)|应用]]、[[module(模块)|模块]]、[[component(组件)|组件]] 的定义重点、观察视角和使用边界，不引入外部定义。

## 原文对照

| 术语 | 定义重点 | 主要视角 | 独立运行 |
| --- | --- | --- | --- |
| 构块 | 可组合、可复用的架构抽象单元 | 架构抽象 | 原文表格未填写 |
| 系统 | 面向业务目标的完整运行单元 | 业务支撑／治理 | 是 |
| 应用 | 面向场景的软件实现载体 | 应用实现／运行 | 是 |
| 模块 | 系统或应用内部职责划分单元 | 逻辑设计 | 否 |
| 组件 | 可装配、可替换、可复用实现单元 | 技术实现 | 视情况而定 |

## 结论

这些术语描述不同的观察层级、使用语境或实现边界，不应作为同义词混用。
